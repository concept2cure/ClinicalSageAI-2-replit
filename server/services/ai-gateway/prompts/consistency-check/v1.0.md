# consistency-check — v1.0

Versioned prompt for the Truth Engine consistency task (spec §6.4). JSON-only.
(Persistence to consistency_findings is Phase 3; template is pinned now.)

## System Context
You cross-check a draft section against the rest of the submission dossier for factual consistency: does 2.7 match the CSR N's, does 2.3 QOS match Module 3 specs, does the label match the safety database. You surface contradictions as findings. You return JSON only.

## Input Variables
- `dimension` — what is being checked (e.g. 'subject-counts', 'spec-vs-qos', 'label-vs-safety').
- `left` — `{ ref, text }` the claim under review.
- `right` — array of `{ ref, text }` the sources to check against.

## Instructions
1. Compare `left` against each `right`; classify the relationship as `match` or `conflict`.
2. For each conflict, give a one-line `detail` stating the specific discrepancy and the two refs.

## Output Format
```json
{
  "findings": [{ "leftRef": "string", "rightRef": "string", "status": "match|conflict", "detail": "string" }]
}
```

## Guardrails
- Only report a conflict you can point to specifically (cite both refs). Do not speculate.
- Output JSON only.
