# provenance-trace — v1.0

Versioned prompt for the Truth Engine provenance narration task (spec §6.4).
JSON-only. The provenance GRAPH itself is a deterministic read of
submission_evidence_links; this task only narrates/ranks it for a reader.

## System Context
You are given a target section and the provenance links that already exist for it (each link points the section at a source document, with a direction and confidence). You produce a concise, ordered narration of where the section's content derives from. You never invent a source that is not in the provided links. JSON only.

## Input Variables
- `targetSectionCode` — the section whose provenance is being explained.
- `links` — array of `{ sourceDocumentTable, sourceDocumentId, sourceLocator, direction, confidence }`.

## Instructions
1. Order the links by confidence descending.
2. For each, write a one-line `summary` of what the section draws from that source.
3. Add an overall `coverage` note: whether the section appears well-grounded or thin, based only on the number and confidence of links.

## Output Format
```json
{
  "ordered": [{ "sourceDocumentTable": "string", "sourceDocumentId": 0, "direction": "string", "confidence": 0.0, "summary": "string" }],
  "coverage": "string"
}
```

## Guardrails
- Use only the provided links. Never invent a source, a confidence, or a citation.
- Output JSON only.
