This spec names no new screen, route, service, table, mount, AnA tool or component file. Every change completes,
fixes or converges an existing stylesheet or component, which is named by path. D0 ships **CSS first**. The
alias technique in §4 makes every surface render the canonical primitives on the day D0 lands. That includes the
roughly 60 surfaces that no D package owns. No surface's markup has to change first.

**Files D0 changes.** These are its ledger paths. Every commit carries `Plan: D0` and

**Ledger mismatches.** These need no change to proceed, but D0 records them:
- The ledger lists `client/src/concept2cure/v2/useDialog.tsx` and `client/src/concept2cure/v2/Toast*.tsx`. The real
  files are `useDialog.ts` and `toast.tsx`. The gate's glob (`scripts/ci/check-one-design-plan.mjs` `globToRegExp`)
  is case- and extension-exact, so a D0 commit that touched either file would be refused. This spec changes neither.
  The toast and dialog work is CSS only. If a later change needs them, it goes under F1 or through a `Plan: PLAN`
  ledger fix.
- `client/src/concept2cure/v2/ui/**` does not exist, and D0 does not create it. RULE 6 says the canonical
  primitives are the existing classes and components named here.
- `design-system/CLAUDE.md` is a plan file. It still says "Body = 13px" and "Never ALL CAPS except 10px metadata
  labels". Plan §2 supersedes it, and its own header already says so. D0 does not edit it, because only a
  `Plan: PLAN` + `Founder-Decision` commit may. This is reported in §7.

**Order with D1–D7.** The plan's §4.6 forbids two sessions on one file. `styles/**` is in every D package's paths,
so D0 lands in this order:

1. **D0-1, tokens and type.** One commit. Its files: `design-system/colors_and_type.css` and `app-v2.css`, the root
   only.
2. **D0-2, the primitives.** One commit. Its files: `app-v2.css` plus the deletions of duplicates in the shared
   sheets. D1–D7 rebase onto it.
3. **D0-3, the sentence-case sweep.** One commit across every v2 stylesheet. It is mechanical and lands in under an
   hour, because every D package edits these sheets. Announce it before pushing, and rebase onto it.
4. **D0-4, the components.** `AnswerLead.tsx` and `icons.tsx`.
5. **D0-5, the design-system docs and specimens.**
6. **D0-6, retirement.** It runs when the ratchet (§4.6) reaches 0 for a family. It deletes that family's alias
   selectors and retired blocks. This step is gated by `ci:undefined-css-classes`, which fails if a class is
   removed while still in use.

### 3. Claude's pattern: the canonical set

**Character.** The frame is quiet and the content leads. The colour roles are:
- `--bg-000` for the page and cards;
- `--bg-100` for the rail, tracks and quiet fills;
- `--canvas-elevated` for the composer, menus and dialogs (`#fff` light, `#30302e` dark);
- `--border` for hairlines;
- `--text-100` for primary text, `--text-200` for body and controls, `--text-300` for secondary text.

`--text-400` is used only on `--bg-000`, where `ci:token-contrast` proves 4.5:1. Orange
(`--accent-strong`, `--accent-100`) appears only for:
- the send button;
- the ✻ spark;
- focus indicators;
- **at most one** `.btn.primary` per view.

Status colour (`--success`, `--warning`, `--error`) appears only where it means something, and always with text or
an icon beside it.

**Layout grid.**
- The rail is 264 / 56px (D1) and the topbar 48px (D1).
- The page container `.page-inner` is `max-width: 1120px`. Its padding is `32px 40px 96px`, then `24px 24px 80px` at
  1023px and below, then `20px 16px 72px` at 640px and below. That gives the 16px phone gutter.
- The conversation column is `--content-max` (768px).
- The project page is a `1fr` main column and a 320px "Project knowledge" column with a 32px gap (D3).
- In the artifact split, the conversation keeps at least 420px and the panel takes the rest (D4).
- Vertical rhythm: header to content 24px; section to section 32px; section heading to body 12px; card padding 16px;
  card grid gap 16px; list rows 10–12px vertical padding.

**Type scale.** New tokens go in `design-system/colors_and_type.css` §3. The sans is the system stack; the serif is
Lora.

| Token | px / line-height | Family, weight | Use |
|---|---|---|---|
| `--fs-greeting` | 32 / 1.2 | Lora 400 | The Home greeting (D1) |
| `--fs-title` | 26 / 1.25 (22 at ≤640) | Lora 500, −0.01em | Page title (`.ph-title`): Projects, a project, every work area |
| `--fs-section` | 15 / 1.4 | sans 600 | Section heading (`.pj-sec-h h2`) |
| `--fs-body` | 14 / 1.5 | sans 400 | UI body, the root of `.c2c-v2`, `p`, inputs, tabs |
| `--fs-small` | 13 / 1.5 | sans 400–500 | Secondary lines, table cells, buttons, labels |
| `--fs-caption` | 12 / 1.4 | sans 400–500 | Chips, timestamps, table headers. **The floor:** no text below 12px |
| `--fs-prose` | 16 / 1.65 | Lora 400 | AnA's prose (`.prose-reading`) and documents (`.doc-content`, 1.7) |

Weights stop at 600. Mono (JetBrains) is used only for regulatory codes the person reads (CTD §3.2.S.4.1, a
sequence number), never for internal ids. Sentence case everywhere: **no `text-transform: uppercase` anywhere**,
and no positive letter-spacing on labels.

**Radius.**

| Element | Radius |
|---|---|
| Chips | 6 (`--radius-md`) |
| Buttons, inputs, tabs' focus | 8 (`--radius-lg`) |
| Segmented track | 10, items 8 |
| Cards, menus, the artifact panel | 12 (`--radius-xl`) |
| Centered dialog | 16 (`--radius-2xl`) |
| Composer | 20 |
| Avatars | full |

**Elevation.**
- Cards: none. A hairline only.
- Composer: `0 1px 2px rgb(20 20 19/.04), 0 6px 20px -8px rgb(20 20 19/.10)`. In dark, `rgb(0 0 0/.30)` and `/.45`.
- Menus and dialogs: `--v2-shadow-lg`.
- Drawers: `--v2-shadow-lg`, on a scrim with **no blur**. Blur stays reserved for ⌘K (`design-system/README.md`).

**Motion.** `var(--dur)` (200ms) with `var(--ease)` (ease-out) for every transition and entrance. There is:
- no `transform` on hover;
- no bounce;
- an entrance of opacity plus 4–16px of translation;
- `prefers-reduced-motion: reduce` turns every entrance off.

**Components.**
- **Button.** `.btn` is ghost by default: transparent, no border, a hover fill. `.btn.ghost` is the hairline
  secondary. `.btn.primary` is the one orange action. Heights are 32px for `.btn`, 28px for `.btn.small` and 36px
  for drawer footers. Under `pointer: coarse` the height is 44px. Text is 13px weight 500 and icons 16px.
- **Input.** Radius 8, a `--border-control` border, 14px text. Height is 32px inline (`.c2c-input`) and 36px in
  forms (`.de-input`). Focus is a `--border-focus` border plus a 3px `--accent-000` halo, as **one** ring. Under
  `pointer: coarse`: 44px and 16px text, so iOS does not zoom.
- **Card.** `.pj-card`: 12px radius, a 1px `--border`, `--bg-000`, 16px padding, and no header band. When the card
  is clickable, hover is `--bg-050` with a `--border-strong` border.
- **Segmented.** A `--bg-100` track with 2px padding. Items are 28px high. The active item is `--bg-000`
  (`--bg-200` in dark) with a hairline ring.
- **Tabs.** 36px items at 14px weight 500 `--text-300`. The active tab is `--text-100` with a 2px `--text-100`
  underline, not orange. The row scrolls horizontally and never wraps to two rows.
- **Chip.** 12px weight 500, `2px 8px`, radius 6, sentence case, its first letter capitalised. Neutral is
  `--bg-100` / `--text-200`. ok, warn and err use their `--*-muted` fills.
- **Page header.** An optional quiet context line (13px `--text-300`), then the Lora title, one line of description
  (14px `--text-300`, 68ch), and on the right `.ph-acts`: one primary and quiet secondaries.
- **Empty state.** No box. One sentence (14px weight 500 `--text-200`), an optional hint (13px `--text-300`) and one
  ghost action.
- **Toast.** A dark pill at bottom centre, 13px, a 200ms fade-up.
- **Drawer and inspector.** 440px from the right on a scrim. The header is 16/20px with a 16px weight-600 title and
  a 32px close. The footer actions are right-aligned. Docked (`[data-docked]`), it is a 360px column with no scrim.
- **Artifact panel.** A 48px header holding the title (14/600), the version and project line (13 `--text-300`) and
  32px icon actions. The body is Lora 16px/1.7, 72ch, padded 32/48.
- **Composer.** `--canvas-elevated`, radius 20, a hairline and the soft shadow. The textarea is 15px. The send
  button is a 32px orange square at radius 8.
- **Answer lead.** A quiet block: a 13px question line, a 15px weight-600 answer, a 14px `--text-300` body and a
  ghost action. Serif only at `data-emphasis="verdict"`.
