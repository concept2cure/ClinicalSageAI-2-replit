# Backlog Index

This directory contains execution backlogs for major epics in Concept2Cure's UI/UX build, aligning the high-level roadmap with implementable tasks.

## Epics

- [Project Workspace Shell](epic_project_workspace_shell.md) – Defines the layout and navigation of the unified 3‑pane workspace (AppShell, ProjectSidebar, ContextPanel, and global create button).
- [Client Portal V2](epic_client_portal_v2.md) – Covers sponsor onboarding, tenant configuration, vault structure, roles/SoD, and launch readiness for the next‑generation portal.
- [Project Cortex](epic_project_cortex.md) – Focuses on data ingestion, mapping, outputs, validation plan, and release readiness for the analytics engine.

## How to Use

Each epic file contains user stories, acceptance criteria, and tasks. Developers should review the relevant epic before starting work on a feature. The backlog aligns with the project roadmap to ensure the UI shell, modules, workflows, artifacts, and PM documents are delivered in sequence.
