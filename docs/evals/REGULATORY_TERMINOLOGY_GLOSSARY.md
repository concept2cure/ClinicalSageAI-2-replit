# Regulatory Terminology Glossary (Medical Writing)

**Status:** Active glossary  
**Date:** 2026-03-27

Reference terms for consistent life-sciences regulatory writing during Reasoning Tier-assisted drafting.

---

## Core Terms

- **Indications for Use**: Statement describing intended patient population and purpose.
- **Contraindication**: Situation where device/drug use should be avoided.
- **Benefit-Risk Profile**: Balanced view of expected benefits versus known/potential risks.
- **Substantial Equivalence (510(k))**: Comparison basis against predicate with appropriate scope.
- **Clinical Evidence**: Evidence from clinical data sources supporting claims.
- **Post-market Surveillance**: Ongoing safety/performance monitoring after market entry.

## Style Controls

- Prefer "supports" / "suggests" over absolute certainty language when evidence is mixed.
- Use explicit scope qualifiers for population, endpoint, and timeframe.
- Keep risk language concrete, specific, and actionable.
- Avoid introducing new defined terms without first-use definition.

## Consistency Controls

- Terms should be used consistently across sections for the same concept.
- Synonym drift should be minimized when it weakens traceability.
- If terminology changes are introduced, rationale should be documented in review notes.
