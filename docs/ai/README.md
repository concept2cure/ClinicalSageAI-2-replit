# AI Engineering Toolkit

This directory contains operational guidance for AI-assisted development.

## Contents

- [Context Compression](context-compression.md)
- [AI Test Verification](test-verification.md)
- [Checkpointing with Worktrees](checkpointing.md)

## Quick Start

- Run context pack: scripts/ai/context-pack.sh
- Verify tests for changed code: scripts/ai/verify-tests.sh
- Create a worktree: scripts/ai/worktree-new.sh <name> [base-branch]
- Remove a worktree: scripts/ai/worktree-clean.sh <name>
