## A. Working definition of GA

Three GA tiers, narrowed enough to be testable:

**GA-1 — IND-MVP, single biotech, single region (FDA):** First paying biotech can run a Phase 1 IND end-to-end:
- Auth + MFA → Program → ingest CMC sources → ingest preclinical studies → run orchestrator end-to-end → validate (hardened) → e-sign per 21 CFR Part 11 § 11.50 → transmit to FDA-ESG staging → receive ack1/2/3 → view run status + audit + ACKs in UI.

**GA-2 — NDA-full, late-Phase:** GA-1 + async CSR narrative (Move 6) + AI-grounded M3 refinement (Move 5) + real CDISC ADaM → StudyData extractor + eValidator integration + full M2.5/M2.7 multi-study integration.

**GA-3 — MAA-full, multi-region:** GA-2 + real EMA CESP/MHRA/Health Canada/Swissmedic UAT + 6 ICH-aligned regions (UK/AU/CH/BR/IN/SG) promoted from generic-stub validators to agency-specific packs.

**Bar for "first paying customer" is GA-1.**

## D. Discovered gaps the prior audits missed

- `nonclinical-m24-adapter.ts` exports `buildEnrichedM24` that calls the same M2.4 builder the orchestrator uses
