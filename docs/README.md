## Contributing to Docs

1. **Use Markdown** - All docs are in Markdown format
2. **Follow Structure** - Place docs in the appropriate directory
3. **Link Related Docs** - Cross-reference related documentation
4. **Date Documents** - Include last updated date for time-sensitive content
5. **Archive Don't Delete** - Move outdated docs to `archive/` instead of deleting
