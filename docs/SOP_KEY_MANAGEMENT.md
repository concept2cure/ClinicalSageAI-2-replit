# SOP-SEC-001: Electronic Signature Key Management

## 21 CFR Part 11 Compliance

### 1. Purpose
Establish controls for cryptographic keys used in electronic signatures to ensure authenticity, integrity, and non-repudiation.

### 2. Scope
Applies to all signing keys used in IND submissions generated by Concept2Cure.

### 3. Key Custody (§11.10(a))
- **Location**: AWS KMS (FIPS 140-2 Level 2 certified HSM)
- **Access Control**: IAM roles limited to production service accounts
- **No human access**: Private keys never exported or viewed

### 4. Key Generation (§11.10(b))
- RSA-4096 generated within AWS KMS boundary
- No external key generation permitted
- Key alias: `alias/fda-signing-key-{YYYY}`

### 5. Key Rotation (§11.10(c))
- **Frequency**: Annual (automatic via AWS KMS)
- **Overlap**: 30 days dual-key operation during rotation
- **Old key**: Retained for 7 years (FDA retention requirement) then scheduled deletion

### 6. Audit Trail (§11.10(e))
- All signing operations logged to AWS CloudTrail
- Logs immutable (S3 Object Lock, Governance mode)
- Log retention: 7 years
- CloudTrail ARN: arn:aws:cloudtrail:...

### 7. Signature Verification
- Verify via KMS Verify API or published public key
- Certificate available at: [URL]
- Revocation: OCSP responder [URL]

### 8. Disaster Recovery
- KMS key replicated to us-west-2 (secondary region)
- RPO: 0 (synchronous replication)
- RTO: 1 hour

### 9. Change Control
- Any change to key policy or rotation schedule is controlled under Change Control document: `CC-SEC-001`.

### 10. Evidence for Inspection
- Provide CloudTrail logs, key policy, KMS key metadata, SOP reference number, and test logs demonstrating signing + verification.
