# Weave Bio benchmark and Concept2Cure authoring evidence

Reviewed2026-10-26 against Weave Bio's current public site and the actual canonical repository. This replaces the earlier2026-03-19 comparison. Its winner rankings, breadth/performance ratios, claims that competing features were unavailable and claims that Concept2Cure agency integrations were all live were unsupported and are withdrawn. Git history retains the original; it is not product evidence.

## What already exists

Concept2Cure already has one DocumentWorkbench, canonical filing/section/template records, project/Vault/data-room source intake, source span attribution, manual and AnA drafting, tracked remedies, versioning, independent review/signatures, export and an authority-question register. The implementation and verified boundaries are recorded in `docs/design/US_BIOTECH_AUTHORING_COMPLETION_2026-10-26.md` and `docs/evidence/D2-US-BIOTECH-AUTHORING/2026-10-26/`. Template existence, blueprint coverage and a registered gateway do not establish full customer workflow qualification.

## Current implementation findings

The audit found concrete defects, not an empty platform: missing clinical metadata blocked AnA despite existing outlines; early IND protocol selection loaded CSR material; detailed lifecycle records lacked distinct editor starts; non-IND biotech Plan and filing-aware creation were incomplete; authority answers used a second textarea. The linked workstream corrects these through existing owners and retains actual prepatch failures and final workflow receipts.

The existing registry includes US medicinal filings, but that denominator alone misses vaccine EUA and combination-product RFD. Their current source scaffolds have scope limitations. Expanded-access variants, biologics-specific reporting, retained sponsor formatting, structured labeling/safety output and live agency/provider operation each require their own applicable source and workflow evidence. A general working outline does not close these gaps.

## Completion rule

There is no supported statement that Concept2Cure does everything Weave does, exceeds it, or is ready for every biotech filing. Use the canonical coverage report and `docs/biotech/BIOTECH_DOCUMENT_COMPLETION_MATRIX.md` to inspect each observed capability, its real tests and remaining limits. No performance or regulatory-readiness claim follows from counts or this comparison. Human experts remain responsible for scientific and regulatory review and final decisions.
