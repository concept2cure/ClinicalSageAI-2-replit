Each retry repeats only its read, not governed toggles; in-flight loading is visible and repeat dispatch is prevented. An absent catalog (including null/204) is locally unavailable; `{modules:[]}` is genuine empty. Preserve shape validation, active-session transport, late-read cancellation and user feature/search state where applicable. Use the existing scoped styles to keep recovery text/actions and the task-board header usable on phones, with real browser failing/passing layout checks. No automatic retry loop, new dependency, schema or global hook change.
2. AnA must not claim zero/missing work when the board reports unread stores. A matching readable task remains openable; an unmatched task on an incomplete board returns an honest incomplete-read refusal. A partial flag without source names must also qualify the visible board and AnA counts, with generic human wording; absence of names is not proof of completeness. The nonempty partial warning also offers the existing board reload, so readable cards need not disappear just to recover missing work. Complete empty and complete not-found behavior stays distinct.
3. Resolving a named project after the project-options read fails returns a read failure, not a nonexistent-project claim. Locally guard this existing read's container and the project identifiers/names used by its resolver; malformed success is a read failure, including an invalid later row. Show that failure beside the existing filters with a manual retry of this read and visible loading, retaining readable tasks. Clearing to all projects or using filters that need no project lookup may still work. Validate the whole filter before changing any filter state; a refused combined filter makes no partial change. Preserve loading readiness and in-progress canvas/signature guards. No task-modal or global project-reader expansion.
