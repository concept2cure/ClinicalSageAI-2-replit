## Contract

- Project and exact saved filing binding govern requirements; missing, refused,
  loading and genuinely unbound context are distinct.
- Use the same canvas/editor. Adapt tools inside it, with no new app, card,
  standalone screen, editor, API mount or data store.
- Editing affects a working copy. Save, review, signature, explicit Vault filing
  and submission keep their existing gates and lineage.
- Captured snapshots disclose their basis. No invented historical version,
  inherited signature or qualification; machine-origin adoption holds remain.
- Preserve filing distinctions: applicable FDA device eSTAR versus MDR/IVDR
  technical documentation. eCTD is not a universal MDX filing format.
