A selected section's new status/content appears in the outline, while the editor and its handoff retain old content until the user reselects the row. The base had a selected-object cache but no functional standalone regeneration handler; this PR introduces the trigger path. Historical coauthor file is absent at October HEAD.

Retain compatibility redirects or update the still-visible links to their canonical destinations. This is distinct from deleting genuinely orphaned routes. The October App.jsx has been replaced with a unified shell, so historical links require current-path verification before treating as open defects.
