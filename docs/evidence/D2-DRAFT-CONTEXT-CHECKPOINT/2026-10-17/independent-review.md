## Scope and final qualification

The test imports the actual source producer, identity/window code, drafting service, error classifier and batch receipt formatter. Catalog reads and current actor/program checks are explicit synthetic seams. A partial gateway mock retains the actual error classes and replaces `getGateway` with a stand-in that invokes a supplied callback just before its provider stand-in; it makes no network call. The capacity-wait case therefore checks that the actual service supplies a functional current-source guard. It does **not** exercise `gateway.ts` semaphore, fallback, retries, cancellation or provider-health accounting; the gateway owner's actual-gateway tests qualify those separately.

The runner binds `gateway.ts` and its types so integrated source changes are visible, but loading its exports and recording its hash is not execution of its routing/provider path. Authority revocation and private-parent denials in this suite are controlled seam outcomes, not database/RLS policy proof. No database/provider/agency operation or credential configuration was performed.
