## What already exists

* `server/services/corpus/drizzle-corpus-writer.ts` and
  `scripts/ingest-corpus.ts` ingest CT.gov registry metadata into tenant-owned
  `csr_reports` / `csr_details`. They do not retain report PDFs and do not admit
  globally public documents. This change preserves that path.
* `server/services/clinical-regulatory-evidence/evidence-spine.service.ts` is
  the canonical source store, with explicit `global_public`, original pointers,
  checksums, provenance, versions and honest ingestion/extraction statuses.
* `migrations/20261008c_data_room_source_text.sql` already provides source text,
  page counts and extraction timestamps. Its client Data Room search is scoped
  to private projects and is not repurposed for public evidence.
* `server/services/ana/AnaToolExecutor.ts` and
  `qms-labeling-analytics-tool-defs.ts` already expose
  `search_clinical_regulatory_evidence`. Its four existing entity types did not
  return source reports. This work extends that tool with sources and bounded
  page reads; it creates no second evidence database or new AnA tool.
* `csr-intelligence-library.ts` has deterministic extraction with supporting
  spans. That extraction is not scientific qualification or evidence that a
  synopsis is a complete CSR. This seed creates no findings or design lessons.
* `server/services/storage/` preserves tenant-owned originals. This curated
  public reference release uses content-addressed original PDF assets under
  `server/data/public-csr-reference/`, which the production image already copies.
  It never passes a null organization through tenant storage authorization.
* `scripts/db/migration-set.mjs` is the deploy seed authority. An ordinary push
  does not deploy: `.github/workflows/deploy-aws.yml` requires an explicit
  release dispatch/tag and release gates.

## Admission contract

The deploy seed distinguishes two states. Retained, permitted reference
documents carry their unchanged original PDF, an attributed page derivative,
original and derivative SHA-256, and an explicit document class. Catalog entries
whose content is not admitted carry source links, identity, scope and an honest
use restriction; they cannot return report text. Sponsor reports do not become
public-domain documents because a regulator hosts a copy.

`metadata.publicReference` is a versioned contract. All records are
`external_reference`, `clientStudyEvidence=false`, and `trainingApproved=false`.
The reader requires an explicit global source, no private project binding,
current/nondeleted status, a permissible retrieval disposition, complete page
offsets and hashes, and matching retained PDF bytes before returning content.
An extracted page is still `extracted_unreviewed`; OCR is identified separately.
No redacted material is reconstructed. Tables and figures are not represented
as semantically validated by a successful text extraction.

The seed generator verifies actual original and page bytes before producing a
replayable migration. The migration inserts immutable version identities,
does not overwrite an existing source, and asserts the expected row count.
Study-family grouping is retained: multiple reports, protocols and SAPs from a
single study are not independent training/evaluation samples.

## LMN-201 scope

Public registry and sponsor announcements are versioned contextual sources,
not the client's final study record. RePreve registry phase/enrollment and the
October 2026 announcement differ. Final protocol/amendments, approved SAP,
analysis populations, TLFs, database-lock evidence and safety narratives remain
necessary for the client CSR. A literature example cannot resolve those facts.
