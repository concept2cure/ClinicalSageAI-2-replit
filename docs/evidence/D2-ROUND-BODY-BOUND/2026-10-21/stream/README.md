## Controlled boundaries

The natural crowded and impossible-passage cases run the existing canonical
allocator; the replan case runs the real Manual checkpoint. Raw UI results,
call identity/order, exact framed request bodies, in-memory recorder blobs and
grounding corpus are compared. The record writer is substituted to seal and
capture the failed turn in memory; it does not prove a database write.

Explicit budget/guard/settlement overrides inject exact 24,000-character arrays
and one-character late growth to qualify host ordering. They do not claim real
source revalidation or receipt transaction behavior; the classic and existing
source suites qualify those. An accepted 8,219-character fixture isolates the
second-cap drift seam and does not qualify the allocator's per-result cap.

without requiring one exact production message wording.

The two passing controls retain a fitting ordinary miss's body/guidance and a
complete passage's source locator/escaped framing. Synthetic tools/providers,
database/context and durable post-processing do not qualify live retrieval,
provider service, multilingual quality, persisted receipt writes or agency
acceptance. The guarantee is raw UTF-16 body totals, with framing/history costs
outside it; failure never claims action rollback.
