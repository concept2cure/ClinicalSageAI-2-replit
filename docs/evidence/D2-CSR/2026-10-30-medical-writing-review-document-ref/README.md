## What changed

`new server/services/ana/saved-section-writing-review.ts` `reviewSavedSectionWriting` (read-only, no model call):

1. **Validation.** `document_id` must be a UUID. `section` is an E3 number (for example `11.4`) or the saved section id. Combining it with `draft_text` is refused. The tool requires an authorized open project.
2. **Read.** In one snapshot, the module calls `readAuthorizedSavedDocument`. The saved identity must be a CSR (`savedIsCsr`, which includes the import provenance); anything else is refused by name. The section number must be unambiguous; two sections with the same number are refused, and the caller must give an id.
3. **Evidence.** The module re-reads the runs behind the import receipts with `readCsrEvidenceRuns`. It then runs `reviewCsrSectionWithEvidence` over the saved section's stored content, its receipts and the current cells. This produces `sectionGate`, which carries the binding issues plus `NUMERIC_MISMATCH`/`MISSING_SOURCE`/… findings. The whole-document verdict supplies what one section's claim list cannot: the section's issues with the cell named (claimed and current text), `CROSS_SECTION_CONFLICT`, `CLAIM_NOT_STATED`/`FIGURE_CHANGED`, run-level unavailability, and the section's unclaimed figures, each with its blocking flag.
4. **Status.** The status is `blocked` when the gate, any blocking issue or any blocking unclaimed figure says so. It is `not_assessed` when the document carries no receipts, or when this section has none and states no figure that must be claimed. Otherwise it is `reconciled_pending_human_review`. `readyForApproval` is always `false`.
5. **Result.** The evidence verdict comes first and whole, followed by `writing` (the existing review). The result stays within `capToolResultForModel`'s 8000-character per-result ceiling, so the model never receives a result cut in the middle. When the whole result does not fit, `structureCoverage` and the structure checklist items are dropped, and the result says so (they restate `missingSections`). If it still does not fit, the call is refused.

The register entry is unchanged: `class: read`, `writes: none`, `source: authoring`, verb "review". The new path reads the database and writes nothing, so the entry is still true. `npm run ci:step-presentation` passes (655 in-scope tools, 134 engine claims, none reaching a model).
