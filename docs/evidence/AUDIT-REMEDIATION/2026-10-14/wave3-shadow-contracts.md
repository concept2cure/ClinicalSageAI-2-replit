# Wave 3 — legacy Shadow program route contract

Approved scope: the existing defense-packet and SE-matrix BFF routers. These routes are mounted under `/api/programs`, belong to the fenced device-510k surface, and have no current client caller for these exact endpoints. MDX K510 uses the different `/api/predicate-intelligence/se-matrix` API. No launch activation is introduced.

The deployed stores are `predicate.defense_packets`, `predicate.proof_pack_exports`, and `predicate.render_jobs`, as created by the registered 20260211 migrations. The ORM's `public.defense_packets` is not their physical store. Initial native catalog inspection found app_service SELECT permission but no RLS policy on these three predicate tables. The control tower subsequently amended and replayed the existing canonical parent-scoped migration: all three now have FORCE RLS derived through their real programme/proof parents. The BFF must still prove exact programme binding with parameterized queries, after the canonical live-program ownership check, current organization membership, and the current private-project policy through the existing `projects.regulatory_program_id` bridge. Proof exports also bind their packet, and render jobs derive their programme through their actual proof export FK and that export's packet. An absent binding is 404; a verification/store failure is 503; neither permits an external call.

Actual audit-write results are combined across the request and returned through the canonical audit headers, preserving transparent JSON and binary body compatibility. No audit call means no invented audit result. A successful upstream mutation followed by an unverifiable readback is an explicitly unconfirmed operation with a recovery path; it must never say that nothing was written or encourage an automatic retry. Readback cannot make an external service transaction atomic with the BFF; downstream service credentials, worker behavior, provenance, and agency qualification remain independent unqualified boundaries.

The old task-waiver handler only wrote an audit event and unconditionally claimed `waiver_recorded:true`; there is no canonical waiver mutation in this checkout. It will refuse with 501 and `waiver_recorded:false` before any write. The SE-matrix `/render` handler only generated a timestamp-based fictional job ID after payload generation; it will refuse with 501 and `renderJobId:null` before generation. Safety-signal ingest sends user input into a tenantless global K-number corpus; it will refuse with 503 before an external call until an authoritative governed ingest contract exists. These are corrections of unsupported outcomes, not new engines or parallel stores.

The Shadow FastAPI endpoints themselves are absent from this repository. `docs/operations/predicate-intelligence-shadow-service.md` identifies a separate predicate-shadow-service repository. No mock response or BFF test qualifies that external service.

Verification will include red/green route tests, exact transparent payload/binary audit warnings, denied-object no-outbound checks, and native app_service reads against the actual registered migration DDL with positive and private/foreign negatives. No dependencies, migrations, baselines, or UI changes are in this scope.

Although `20260212_phase7_0c_render_tenant_safety.sql` exists in the repository manifest, it is absent from canonical `C2C_MIGRATION_FILES`; `predicate.render_jobs` therefore has no `program_id` on this installation. The implementation uses the real registered `render_jobs.proof_pack_id` FK and both parent programme identities. No schema or fixture column was added to make the test pass. This also leaves the separate upstream service's optional newer schema and workers unqualified.

That first checkpoint preceded the parent-policy correction; its missing-RLS observation is retained as history, not the final schema verdict. The final checkpoint below verifies both the database policy and the BFF predicates. The test controls external fetch responses only; it does not mock `pg`, invent a schema, or claim a real Shadow render occurred.
