# The seven defects, before and after

Each was found by probing the rule with register-shaped text, not by reading it.
The probe is probe-q1e-edges.ts in this directory (run with: npx tsx <path>).

## Before
```
monthsIn("1.5 years")                        12      <- the fraction was discarded
monthsIn("0.5 years")                        0       <- half a year was no months
monthsIn("1000 months")                      0       <- \d{1,3} backtracked onto "000 months"
latestTimePoint("[0,3,6,12,24]")             12      <- the brackets ate the ends

refrigerated product (LT 5C, ACC 25C):
  longTermCoverage                           6       <- the ACCELERATED study, matched as long-term
  verdict          Q1E_EXTRAPOLATION_BEYOND_LIMIT / fail   <- a compliant dossier failed

intermediate only, 30C (Zone II):
  longTermCoverage                           12      <- an intermediate study as long-term
  verdict          Q1E_CLAIM_WITHIN_DATA / pass            <- passed on no long-term data

DS retest 60mo beside DP shelf life 24mo:
  statedClaim      {"months":60,"study":"DS retest"}
  verdict          Q1E_EXTRAPOLATION_BEYOND_LIMIT / fail   <- DS claim vs DP coverage

readable "12 months" beside unreadable "thirty-six months":
  statedClaim      {"months":12,"study":"LT-12"}            <- the other was dropped
  verdict          Q1E_CLAIM_WITHIN_DATA / pass            <- a PASS over an unjudged claim

nonsense "1000 months" claim:
  statedClaim      {"months":0}
  verdict          Q1E_CLAIM_WITHIN_DATA / pass            <- a PASS over nonsense
```

## After
```
── the parser ──
monthsIn("1.5 years")                        18
monthsIn("0.5 years")                        6
monthsIn("1000 months")                      null
monthsIn("24M")                              null
monthsIn("2-year")                           null
monthsIn("18 months")                        18
monthsIn("24 months")                        24
monthsIn("36 mo")                            36
monthsIn("NMT 24 months")                    24
monthsIn("at least 24 months")               24
── time points ──
latestTimePoint("0,3,6,12,24")               24
latestTimePoint("[0,3,6,12,24]")             24
latestTimePoint("0, 3, 6, 9, 12")            12
latestTimePoint("0,6,12,18,24M")             18
latestTimePoint("T0,T3,T6")                  null

── a refrigerated product: long term 5C, accelerated 25C ──
longTermCoverage                             24
verdict                                      [["Q1E_CLAIM_WITHIN_DATA","pass"]]

── intermediate only, 30C (Zone II: intermediate, NOT long term) ──
longTermCoverage                             null
verdict                                      [["Q1E_COVERAGE_NOT_READABLE","not_evaluated"]]

── a DS retest period beside a DP shelf life ──
statedClaim                                  {"months":60,"study":"DS retest","raw":"60 months"}
verdict                                      [["Q1E_EXTRAPOLATION_WITHOUT_ACCELERATED","fail"],["Q1E_EXTRAPOLATION_BEYOND_LIMIT","fail"],["Q1E_CLAIM_WITHIN_DATA","pass"]]

── a readable 12-month claim beside an UNREADABLE larger one ──
statedClaim                                  {"months":null,"raw":["thirty-six months"]}
verdict                                      [["Q1E_CLAIM_NOT_READABLE","not_evaluated"]]

── a nonsense 1000-month claim ──
statedClaim                                  {"months":null,"raw":["1000 months"]}
verdict                                      [["Q1E_CLAIM_NOT_READABLE","not_evaluated"]]
```
