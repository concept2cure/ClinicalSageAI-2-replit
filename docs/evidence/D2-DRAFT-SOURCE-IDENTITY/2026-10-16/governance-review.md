# Selected drafting source governance

16 October 2026. This owner implements the approved [contract](CONTRACT.md) within the existing source-reference and authoring save paths. This evidence is scoped to the source-integrity part of D2.

New reference inputs require version 2, original-byte identity, exact full-extraction and excerpt digests, and explicit safe-integer UTF-16 coordinates. The decoder strips caller text, qualification and authority assertions; it snapshots coordinates and rejects accessors, sparse selections, partial identities and numeric-string coordinates. Direct typed verifier calls undergo the same runtime checks before their first asynchronous operation.

New saved groups carry `sourceReferenceVersion: 2`. Current canonical source reads recompute both text digests using the producer's one identity factory. A same-length correction anywhere in the extraction refuses verification, including outside the selected excerpt. Verified new entries retain `identityVerification: exact_extraction_and_span` without a second source-text copy. This identity does not establish generation, provider delivery, comprehension, scientific validity or claim-level support.

Saved-only compatibility decodes historical unversioned groups under their original byte/length semantics. It never manufactures historical extraction digests. Partial V2 markers cannot fall back to that compatibility path. If every version and digest marker in trusted persisted provenance were erased, this mechanism would not detect that as tampering. Existing audit history is not rewritten.

New saves and source-linked renditions share `reserveDraftSourceStores`: the existing canonical program advisory lock, followed by the Vault document/catalog SHARE reservation. Existing transaction commit/rollback owns its lifetime. Import-only exports retain their exact-origin row reservation. Canonical current actor, recorded project, current-version and data-withdrawal checks remain in the existing source loader; historical receipt IDs grant no authority. Eligible retained text remains usable with current original-availability caveats.
