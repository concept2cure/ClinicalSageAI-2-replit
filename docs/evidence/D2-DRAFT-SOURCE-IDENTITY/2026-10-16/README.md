# D2: exact extraction identity for selected drafting sources

This increment keeps a selected draft reference tied to the exact extraction and excerpt supplied to AnA. A same-length OCR correction can no longer silently change what its saved coordinates identify. It improves traceability for life-sciences drafting within the existing Vault and Authoring modules; it does not close launch D2.

New selected sources carry V2 identities: original-byte hash, full-extraction SHA-256, excerpt SHA-256 and absolute half-open UTF-16 coordinates. New writes require complete V2 metadata and strictly bounded input; removing a version or digest refuses rather than selecting historical compatibility. The producer rechecks current source text and actor/program access before returning. New saves and source-linked renditions use one canonical source-store reservation helper through commit or rollback. Reference identities add hashes and coordinates without another source-text body; existing bounded claim/figure quotations remain.

Historical saved references retain their weaker `legacy_original_bytes_only` semantics and existing authority checks. Their digests are never backfilled from today's extraction. The tool accepts actual absolute windows beyond character 80,000; width and aggregate budgets remain enforced. These identities prove neither model use nor scientific support for a draft.
