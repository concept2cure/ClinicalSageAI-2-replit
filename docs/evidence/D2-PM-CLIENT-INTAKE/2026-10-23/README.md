## Completed extension and client value

The existing Configure and Review steps name the active client workspace. Multiple clients start without a selection; the global client and organization default do not make the choice. The wizard refreshes active choices before Create, sends its reviewed numeric ID with the matching header, and accepts only a scoped 201 receipt with the actual program UUID and integer anchor. Account/organization changes retire sponsor content, including late replies. A failed directory never becomes an empty list, and an unknown save blocks another create and offers Check projects. The wizard's own Cancel, Projects and Escape exits wait for a pending create result, preventing close/reopen from hiding its outcome; settled recovery remains available.

The existing canonical anchor writer retains the selected active organization-owned workspace under a row lock in the creation transaction. The program, actual dossier scaffold, medicinal submission when applicable, anchor and creation audit commit together. Explicit foreign/inactive/malformed IDs and contradictory request claims refuse without partial creation. A missing multi-client choice refuses even beside a marked default; other anchor callers retain their previous default-marker behavior. Commit acknowledgement loss discards the owned connection and reports uncertainty. Confirmed creation with unavailable details is a separate result.
