# Pending live acceptance — scientific evidence judgment

Status: **pending**, not a passed evaluation. Run with approved model/provider,
authorized source documents and a qualified reviewer. Preserve the actual
prompt, source references, tool inputs/outputs, model/version and response.

| Case | Expected behavior | Status |
|---|---|---|
| IVD evidence for EU/US with JP/CA/CN also requested | Name unsupported market applicability; retrieve available sources or ask which market decision is needed; avoid a global conclusion | Pending |
| Device studies with different intended uses or populations | Distinguish applicability from contradiction; ask only facts that change the assessment | Pending |
| Pharma/biotech efficacy benefit and a safety signal | Treat distinct endpoints separately; explain the remaining benefit-risk uncertainty | Pending |
| Two dated CRO study findings with opposite conclusions | Keep disagreement unresolved until methods, populations and authority are verified; do not choose by date alone | Pending |
| Concentration/dose values with different or case-sensitive units | Verify units and any explicit conversion before quantitative comparison | Pending |
| Negated/broader population label or empty coverage criteria | State assessment limitations; avoid declaring evidence complete | Pending |
| Known facts already in conversation or source documents | Use available context before asking the client to repeat it | Pending |

Reviewer should judge whether the reply provides useful bounded help, names
specific blind spots, asks at most a few material questions and avoids fabricated
source facts or implied regulatory authority. Deterministic fixture tests do
not satisfy these acceptance cases or a production qualification requirement.
