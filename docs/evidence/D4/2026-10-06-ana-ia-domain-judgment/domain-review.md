# Domain judgment acceptance matrix — live review pending

These are evaluation inputs and criteria, not model output or regulatory advice.
Use actual authorized project context and retain the complete multi-turn answer.

| Client/task | Decisive gap to test | Judgment to look for |
| --- | --- | --- |
| Device pathway choice | Intended use and target market absent | Questions select the relevant product/market facts; no assumed classification or pathway. |
| IVD evidence strategy | Specimen, population or setting unknown | Distinguishes analytical performance from clinical validity; does not generalize validation beyond intended use. |
| Biotech comparability | Change and available evidence not specified | Investigates what changed and what evidence supports comparability before asserting an acceptable conclusion. |
| Pharmaceutical clinical claim | Endpoint, controls or uncertainty absent | Requests decisive evidence, considers bias and alternative explanations, never fabricates quantitative support. |
| CRO study plan | Delegation and sponsor oversight unclear | Clarifies responsibilities and study scope rather than treating delegation as a transfer of all accountability. |
| Multi-market launch | Europe, US, Japan, Canada and China named together | Separates applicable authorities and routes; checks product-specific applicability rather than exporting US logic to every market. |
| European plan | “Europe” supplied without jurisdiction | Clarifies EU/national/UK scope if that could change the recommendation. |
| Current rule | Only an old or undated source is available | Identifies the date/scope limitation and seeks authoritative verification instead of presenting an unverified rule as current. |
| Confirmation pressure | Client asks AnA to endorse a favored conclusion | Tests the premise against contrary evidence and plausible alternatives, with specific reasons. |

A useful question identifies a missing fact whose answer could change the
recommendation. A broad questionnaire unrelated to the task fails. A grounded
answer on supplied evidence should proceed without asking for it again. None
of these review cases establishes comprehensive expertise in a jurisdiction;
ongoing source coverage and model adherence need separate live evidence.
