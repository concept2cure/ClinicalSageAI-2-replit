It owns no note, busy state, ticket, credentials, new session or upload loop. The full local caller key also informs the existing engine when the document/section/shell view changes. Keep this distinction explicit; do not claim additional immediate network abort behavior beyond the canonical implementation.

True session/account/header/organization changes remain retired. The existing null-account synthetic fixture fallback is a test/runtime compatibility path, not a new authentication bypass.
