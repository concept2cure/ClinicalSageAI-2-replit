## What changed

Canonical current membership and existing project sharing determine source read authority, including viewer/custom-role/owner/reviewer reads. Explicit inconsistent project identifiers refuse rather than becoming organization-wide access. Organization-level accessible programmes are derived only after anchor uniqueness is evaluated over every same-organization anchor. Open-project conversations stay in their admitted project.

Existing AnA Vault reads, discovery, selected drafting sources, lexical/meaning/passage adapters, source-file recall and narrow tool-step title enrichment use that authority. SQL filters precede counts, ranking and pagination. Protected queries share a tenant-stamped connection and the current persisted role. Provider waits occur outside these short database wrappers. Final actor/source checks refuse changed scope or sources, including changes during embedding, coverage and display awaits. Keyless lexical search remains available; optional meaning search remains optional. Missing-vector fallback uses an actual transaction savepoint and a narrowly classified missing-vector condition.

Historical by-ID text reads disclose their historical status and cannot earn new current-source receipts. Eligible `keep_data` extracted text remains available with original-unavailable disclosure; original bytes are not reopened. Removed/superseded material cannot become new current source evidence. A legacy extraction without a coherent catalog can remain readable without producing a new receipt. Capture discovery requires consistent current source/upload/program/workspace identity. Truly unbound chat captures require both the persisted creator and upload owner, with every other recorded private parent enforced, including retained/deleted associations. Private titles, IDs, reasons and counts are excluded from evaluated actor-scoped listings.

Both bootstrap paths and explicit recall forward authenticated user and admitted project identity. Missing actor/unavailable source recall is incomplete, not evidence of no records. Existing memory/profile/outcome behavior is outside this source-file increment. Recall wording describes the actor's evaluated source scope rather than all organization files.

Source reads privately freeze exact source/payload snapshots before an await. Host budget acceptance requires unchanged whole strings. Both hosts recheck exact actor/source/extraction before new context is staged. The existing receipt writer repeats checks inside a short READ COMMITTED transaction, uses the canonical disposition/catalog/document/actor reservations, verifies one actual INSERT receipt and checks cancellation before COMMIT. A locally observed source/admission refusal during insertion withdraws every pending Vault read in that round and stops later receipt insertion attempts; earlier actual commits remain historical records. Ordinary receipt persistence denial does not widen read authority or falsely prove a receipt. No lock survives into the gateway call.
