# Node's bundled roots contain no Amazon RDS CA (why the bundle is needed):
$ node -e "console.log(tls.rootCertificates.length, tls.rootCertificates.filter(c=>/Amazon RDS/.test(new crypto.X509Certificate(c).subject)).length)"
144 0

# The bundle loads as NODE_EXTRA_CA_CERTS. Node reads the file lazily, so the probe
# builds a TLS context to force it. Control first: a path that does not exist warns.
$ NODE_EXTRA_CA_CERTS=/nonexistent.pem node -e "require(\"tls\").createSecureContext(); console.log(\"ctx\")"
Warning: Ignoring extra certs from `/nonexistent.pem`, load failed: error:80000002:system library::No such file or directory
ctx
$ NODE_EXTRA_CA_CERTS=global-bundle.pem node -e "require(\"tls\").createSecureContext(); console.log(\"ctx\")"
ctx
