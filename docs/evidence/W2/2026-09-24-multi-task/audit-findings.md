# Audit findings — production as configured (2026-09-24/25)

A multi-agent read-only audit (workflow `d1-production-as-configured`) of what breaks when production runs as configured: two API tasks and a worker from one image, no Redis, no sticky sessions, and only the environment `terraform/stack` renders. Seven auditors, one per failure mode. Each finding went to two skeptics, one asking whether it really fails as configured and one whether it is already handled elsewhere, and it survived only if both upheld it. A completeness critic then named four areas nobody had covered, and those were audited and verified the same way.

**24 confirmed, 7 rejected** (35 raw; same file within 15 lines merged). The full record, including every skeptic's reasoning and the fix-unit synthesis, is in `audit-findings.json`.
