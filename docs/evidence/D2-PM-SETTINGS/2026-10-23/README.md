## Completed extension

Project home now opens a real inline settings panel instead of sending the person back to the portfolio. It reads current saved description, priority and target submission date and current mutation authority. A manager/lead can review actual differences and confirm them with a stated governed reason. The canonical profile writer and chained audit commit together, retaining before/after values, actor, reason and exact parent/revision facts. Another committed change makes the editor stale; it must reload before another proposal. Missing/foreign/invalid scope or unavailable reads never become editable blank defaults.

A confirmed save refreshes the home's metadata and activity while preserving the selected workflow stage. Pending duplicate saves and panel close/Escape are blocked. An uncertain save or invalid receipt cannot be replayed by collapsing and reopening the panel; an explicit reload reads current saved facts without claiming an earlier uncertain write/audit succeeded. Actor, role, account/session, organization, client or program changes retire the draft and late callbacks. Ordinary same-account bearer refresh remains valid.

This gives biotech, pharma, device and IVD teams a common way to maintain their agreed target and project context. Multi-sponsor consultancy teams retain the recorded client parent. Existing lifecycle, classification, owner/signing policy, completed schedule actuals and approved document versions remain governed by their existing paths; the target edit itself does not replan or approve them. This is the bounded supported-field part of PM-06, not an ownership-transfer implementation or a claim that the full PM roadmap is complete.
