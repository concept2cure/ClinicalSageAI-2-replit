# Authority answers in the existing document editor

This slice extends the canonical workflow-source import, Authoring document/section writers and `saveResponseTx`. The response register reviews a saved editor section; it no longer hosts a separate answer textarea. The Communication Center and project Respond step pass their existing navigation callback to that same editor. Approval, response history, commitments and package controls remain on the original question.

## Observed behavior

Exact visible event/question/current answer revision previews into an independent editor working copy. Current database actor, project and letter visibility precede source reads. Fingerprints include the exact source question/answer version; later changes require an explicit fresh preview/copy. Earlier edited copies remain unchanged. The dialog prefers `agency.response` and preserves an explicit selection of `agency.context`.

Explicit writeback sends only the saved document/section IDs, SHA-256, timestamp, expected original question response revision and governed reason. The server reads actual stored content and lineage, rechecks current permission/source/version, then invokes the existing answer writer in its existing governed transaction. It does not accept browser-supplied text or authorship in the saved-editor request. Original revisions/signatures remain independent; a changed answer needs a new independent approval before package assembly. A second amendment starts from an explicitly refreshed source copy.

Known AnA origin survives the response register: a source-only reader checks the existing immutable response history and its canonical governed action/audit pairs, rebuilding the known payload serialization recipe before checking its hash. Current positive revisions require complete contiguous history and one verifiable receipt per revision. Current text retaining known machine clauses remains machine-origin on fresh import; the deterministic import sentinel is not model authorship. Supporting receipt identities/digests bind the source fingerprint, and existing qualification holds remain. Missing, malformed, moved, conflicting or over-limit records refuse. Bounds are200 revisions/400 action candidates; original model qualification is not invented.

The current response register and its package are plain text. Only plain text and unstyled paragraphs/hard breaks are admitted. Pending tracked changes, richer structure, references, media, fields and tables refuse atomically instead of silently losing them. This is an explicit format limitation, not full rich response-package support.

The UI uses existing native controls/classes and the existing SourceImportDialog/DocumentWorkbench deep-link. Its outer host visit uses the canonical Authoring session plus project/letter identity, retires all old question forms synchronously and supplies the shared reader owner. Exact server letter identity is checked. The editor preparation additionally tags every retained state value with its producing visit before render. The same outer predicate guards stale callback initiation and late outcomes, including signing/package delivery. A refreshed server revision also reloads the separate question read; this does not rebase an imported working copy.

## Boundaries

PGlite exercises actual JWT/current admission, Authoring source/import/PATCH/read services, saved-response/revision/history SQL, canonical governed action/audit pair persistence, actual package refusal and successful audited package delivery. Seal computation and signing-authority checks are scripted; seeded signature standing and seeded accepted machine spans are not an actual Part11 ceremony or model-generation turn. These checks establish neither live PostgreSQL/RLS/concurrency behavior, live provider/model qualification, human usability, scientific/regulatory correctness nor agency dispatch. No schema, dependency, parallel editor, source-response writer or deployment is introduced.

Source and production code are frozen on the final35-file snapshot. No jobs are running. Cross-iteration attribution, render-time scope retirement, stale callback initiation and parent read/form retirement were review findings corrected after their recorded failing observations; earlier127-case passes alone did not resolve them. The lead owns global compiler/build/gates, final product claims, branch review and canonical publication.
