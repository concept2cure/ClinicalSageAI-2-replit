# D2 — honest batch draft termination receipts

AnA previously labeled any nonempty batch response as drafted, even when generation ended mid-sentence with `max_tokens`, `length` or `chunk_timeout`. The receipt discarded the existing termination fields and offered successful content for governed authoring.

The canonical receipt now uses the existing finish-reason classifier and the explicit truncation flag. A cut-off response is a failed `DRAFT_TRUNCATED` slot with its original request index, finish reason, safe shorten/split guidance and targeted retry index. Incomplete prose is omitted. Successful siblings retain their generated content and exact source receipts, plus termination metadata. All slots remain unsaved; an absent/unknown finish reason and `truncated: false` do not certify completeness. Existing tool guidance names the drafted-only handoff and failed-slot repair.
