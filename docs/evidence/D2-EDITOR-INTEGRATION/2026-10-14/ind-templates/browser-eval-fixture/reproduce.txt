IND template existing-editor browser evaluation

Scope: W1 / D2. Evaluation only. No production or test files were edited by this session.
Source contract: docs/design/IND_TEMPLATE_EDITOR_EXPANSION_2026-10-14.md
Branch: concept2cure-v2

The saved api-contract.json is generated directly from getIndAuthoringTemplates() and
buildIndDocumentCatalog(), with 200 templates (102 sections, 93 deliverables, five
module outlines) and 2,725 initially empty working sections. It is a browser fixture
snapshot; it is not inserted into production or treated as source evidence.

The fixture renders the real IndDocumentLibrary, DocumentCanvas, DocumentWorkbench
and RichSectionEditor/TipTap. It imports existing component styles and uses the
existing canvas pane portal host. The library stays mounted to exercise the native
receipt state when an open callback is held/canceled and when a copy is reopened.
A fixture callback flag holds the first create/open callback. The real workbench
section unsaved-work guard is separately exercised by typing, switching section,
canceling, checking the preserved body, and leaving without saving.

All /api/** requests are intercepted by Playwright. Unknown endpoints return a
synthetic 404 and fail the run. No AnA, model provider, live API, or database is
called. Mock docs are unbound DRAFTs with exact template/module/project identities,
empty content, and guidance resolved from their saved template and section codes.
The browser evaluates client behavior; server authorization/persistence and the
complete 200-template creation path are validated by separate server/database evidence.

Reproduction in this workspace:
1. Copy probe.tsx, index.html, generate.ts, and api-contract.json from this folder
   to /workspace/ClinicalSageAI/.visual-qa/ind-template-eval/.
2. Optionally regenerate current JSON from /workspace/ClinicalSageAI:
   PATH=/workspace/scratch/editor-toolchain/node_modules/.bin:$PATH node node_modules/tsx/dist/cli.mjs .visual-qa/ind-template-eval/generate.ts
3. Start server.mjs with the Node 22 toolchain (port 5175, strict):
   PATH=/workspace/scratch/editor-toolchain/node_modules/.bin:$PATH node server.mjs
4. In another process, run browser.mjs using the same Node toolchain.
   It uses /usr/bin/chromium, Playwright core at
   /opt/codex/cua_node/lib/node_modules/playwright-core/index.mjs and axe-core at
   /workspace/scratch/editor-ui-tools/node_modules/axe-core/axe.min.js.
5. Stop the server's known PID after the run. Never stop unrelated services.
