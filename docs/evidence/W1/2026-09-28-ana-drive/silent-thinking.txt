A model that thinks is not a stalled stream — 2026-09-28 (third pass)

What a real model does that the stand-in did not: Opus 5.5 always thinks
before it writes, and Opus 5 and Sonnet 5 do unless told not to. With the
default display ("omitted"), none of the thinking is streamed: the API opens a
thinking block, sends only `ping` events while the model thinks, then closes
the block. The Anthropic SDK drops ping events before they reach the caller
(@anthropic-ai/sdk 0.82.0, core/streaming.js: `if (sse.event === 'ping')
continue;`), so the gateway saw nothing at all.

The gateway aborted any stream silent for 30 s. The SDK ends an aborted stream
without an error (core/streaming.js: an AbortError returns), so the gateway
returned content "" with no tool call as a success. No fallback model was
tried. The turn closed with an empty bubble, and Progress read "Finished".

Reproduced by teaching the stand-in to think silently as the API does
(FAKE_THINK_MS: open the thinking block, send a ping every 5 s, then continue),
35 s on "take me to biostatistics", with a real app restart for each run:

The change (server/services/ai-gateway/stream-stall.ts, used by both stream
paths in gateway.ts):
  - Silence is a stall only while text is streaming: 30 s, as before. Text
    arrives as it is written, so a pause there is a dead stream.
  - Anywhere else — thinking, a tool's arguments (buffered until complete:
    no tool here sets eager input streaming), the gap between blocks, a local
    server reading the prompt — silence is the model working, up to 5 minutes.
  - A stall before any text or tool call throws GatewayStreamStalledError
    instead of returning an empty answer, so the next model in the fallback
    chain is tried, and a turn nothing could answer ends as an error the
    person sees. Partial text after a stall is still returned as
    finishReason "chunk_timeout", as before.
  - The browser was never the limit: the stream route already sends an SSE
    heartbeat every 15 s, which resets the client's 90 s idle timer.
