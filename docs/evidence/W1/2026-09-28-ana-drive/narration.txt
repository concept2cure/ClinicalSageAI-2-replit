── What the API documents ───────────────────────────────────────────────────
claude-api skill, shared/model-migration.md, "Text between tool calls comes
back in thinking blocks" (Migrating to Claude Opus 5.5):

  "On Claude Opus 5, the short notes the model writes between tool calls
  (what it just found, what it's doing next) come back as `text` blocks. On
  Claude Opus 5.5, as on Claude Fable 5.1, notes longer than a sentence or two
  come back as progress-update `thinking` blocks, at most one before each tool
  call, and under the default `display: "omitted"` their text is empty - no
  request fails, but a client that renders only `text` blocks goes quiet for
  the length of a long agentic turn. Fix: set `thinking.display: "updates"`
  (beta `thinking-display-updates-2026-08-18`) ..."

  Under "updates": "any `thinking` block with non-empty text is a progress
  update"; a block whose text is exactly "This part of the response was
  interrupted before it finished." stands in for unfinished work; without the
  beta, "updates" is rejected as an unknown display value.

A demonstration is narrated exactly that way: start_product_demo tells AnA,
for each stop, to "narrate its talking point in your own voice ... then make
its move". Opus 5.5 serves AnA's rounds when tiering is off, on a Thorough or
high-risk turn, and when a person picks it. With the default tiering, drive
rounds go to Sonnet 5, which writes its notes as text.

── The fix ──────────────────────────────────────────────────────────────────
  server/services/ai-gateway/progress-updates.ts (new), used by both
  Anthropic paths in gateway.ts:
  - A model that returns its notes as thinking blocks says so in the registry
    (ModelConfig.progressUpdatesInThinking; Opus 5.5 is the only such entry).
  - On such a model, a request that carries tools and has not asked for
    visible reasoning gets thinking {type: adaptive, display: updates} and the
    beta.
  - A thinking block with text is then her note. It is returned as text, in
    its own paragraph, and never as reasoning. The API's placeholder for
    unfinished work is never shown.
  - A turn that asked for visible reasoning keeps display "summarized" and its
    reasoning panel. Its notes arrive there, mixed into the summary.
  server/routes/ana-ri/stream.ts: a round's first words start a new paragraph
  when the text so far does not end in whitespace. The model is still handed
  back its own words as it wrote them.
