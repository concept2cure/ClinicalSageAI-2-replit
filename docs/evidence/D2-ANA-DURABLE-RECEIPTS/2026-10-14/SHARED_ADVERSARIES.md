# Shared exact-source descriptor controls

Prepared before implementation on 14 October 2026 under the published CONTRACT.md. These are pure descriptor controls: they do not establish actual source access, stored slice correctness, database persistence, provider delivery or regulatory acceptance.

The focused corpus owns `shared/ana/__tests__/source-admission-receipts.test.ts`. It will challenge missing/unknown fields; accessor, inherited, symbol and nonenumerable properties; malformed tenant/actor/UUID/SHA identities; all range boundaries including sparse, overlapping and unsorted manifests; Unicode code-point metadata bounds, controls and lone surrogates; private immutable copies and mutations after asynchronous fingerprinting begins. Positive controls preserve viewer/custom roles, disjoint late and adjacent ranges, null serving context and exact opaque context strings. Receipt IDs are supplied by the server and are validated, never generated by this module.

The canonical golden descriptor fixes one late range `[50,70)` and a precomputed independent SHA256 `1c02dabcd3bd527462a693e7934a9f2b1e83eab6ce3891a724803be0f53ef5d8`. Descriptor insertion order and UUID/SHA case normalize to that same identity. Actor, role, source, extraction, ranges, payload and serving context changes must change it; database acceptance time is not accepted as a descriptor field. Hashes/coordinates contain no source text.

Metadata controls mean Unicode Cc (`U+0000..001F`, `U+007F..009F`) and lone surrogates. Role is trimmed/lowercase and bounded to 128 Unicode code points. Nullable context strings are nonblank and bounded to 2,000 code points, preserving exact surrounding whitespace. No reader-role allowlist is invented in this pure validator: fresh persisted role authority belongs to the canonical server admission.

A preimplementation run against an absent module is an import failure with zero executed assertions. It is recorded as such, never described as a reproduced behavioral security defect. The postimplementation behavioral verdict and immutable source manifest will be recorded separately.
