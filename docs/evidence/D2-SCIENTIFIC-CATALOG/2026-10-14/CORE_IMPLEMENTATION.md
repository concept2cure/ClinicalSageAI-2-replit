# Canonical source-fact preview core

14 October 2026, canonical `concept2cure-v2`, baseline `87b27c897c5d1be20b0527009bcaf425ebbf3af6`. This is a local implementation and synthetic fixture verification, not deployment or domain-expert qualification.

The browser-safe transport and structural tool JSON schema live in `shared/ana/catalog-facts.ts`. The canonical pure core re-exports `validateSourceFactBatch`, `verifySourceFactCandidate` and the checker revision from `catalog-fact-verification.ts`. Legacy value-presence verification and the three-argument full-read catalog gate retain their meanings.

The preview checks exact source/version/text identity, source-recomputed text SHA-256, exact half-open quotes, bounded request shape, source-written values and contextual witnesses. It hashes a private sorted JSON snapshot of the candidate. `ok` means the structural/source/transcription binding succeeded; the separate context may still fail or remain not established. Every result explicitly remains `persisted:false`, `reviewState:not_recorded`, `scientificQualification:unassessed`.

The four nonclinical families admit only explicit single-line, semicolon-separated `Label: value` source rows. The row must identify one named metric result and all required context. A source-stated optional qualifier cannot silently disappear from the candidate. Unknown/contradictory qualifiers, compound subjects, multiple results, remote witnesses and unsupported tables/prose do not produce a context pass. Agreement and reference-standard sensitivity, lot/method/configuration/software, result and criterion, specimen/cutoff/population/reference/denominator and analytical design remain distinct.

Clinical verification reuses the existing clinical engine unchanged. It parses only the exact anchor, requires one exact matching frame/written component occupying the complete anchor, complete contextual witnesses, and local `form`/`clause`/`sentence` slot origins. Remote headings, document/table/default/external-record inheritance and figure-only witnesses cannot establish local context. This is a deliberately narrow supported-form preview, not comprehensive clinical document interpretation.

Written precision/sign/exponents, bound direction, approximation markers, range endpoints and units are preserved. Scalar checks use the named result in admitted labelled rows and inspect actual stored text beside clipped anchors. An unrelated cutoff bound cannot invalidate an exact result or conceal a bounded result. Explicitly unqualified CJK layouts permit literal numeric transcription beside CJK particles, while their extraction caveat unconditionally leaves context not established. No multilingual scientific parsing is qualified.

`CORE_RED_LEGACY_CONTEXT.txt` records three failing scientific-context expectations against unchanged legacy value presence, with one faithful control. Subsequent independent review found scalar text, compound subjects, ignored negation, omitted qualifiers, clipped/repeated bounds, remote clinical inheritance and inherited prototype-name discriminants; the fixes remain in the canonical core and independent historical failures are preserved.

Final owned suite: **52/52** (`CORE_OWNED_FINAL.txt`). The five-file corpus/regression run before the last three prototype-refusal cases passed **609/609** (`CORE_CORPUS_FINAL.txt`); the final cross-workstream runner is owned by the lead. Independent scientific primary/held-out expectations are recorded separately, as are the unchanged clinical-engine corpus and legacy key-data regression. No database, RLS, UI, model-provider or agency acceptance claim follows from these pure tests.

Selected typecheck: four owned roots plus 469 imported/ambient sources, **zero selected diagnostics** (`CORE_TYPECHECK_FINAL.txt`), using repository compiler options. This is not a whole-repository typecheck. Lint: baseline canonical core and final four owned files both have **zero errors and warnings** (`CORE_LINT_BASELINE.json`, `CORE_LINT_FINAL.json`). Two intermediate complexity warnings were removed by splitting distinct checks into small helpers.

The prototype preview remains default-off at the service/tool gate. Typed persistence, independent fact approval, computed facts, original-page attestation, table/header adapters and deployment qualification remain outside this slice.
