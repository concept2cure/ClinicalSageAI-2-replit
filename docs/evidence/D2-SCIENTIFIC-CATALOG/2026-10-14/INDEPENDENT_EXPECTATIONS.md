## Source and shape adversaries

An exact supported source statement must retain the supplied original-byte and exact extraction identities. A different document, original digest, extraction digest, range, quote or authoritative server digest refuses source binding. Repeating the value elsewhere cannot rescue a mismatched value anchor. Candidate-controlled status, scientific qualification, actor, authoritative text, computation or page/table locator fields refuse rather than become attestations. Bounds, ranges and approximation must retain their written form; a bound or rounded number is not an exact scalar. No quote or oversized batch may be clipped into validity.

## Registered tool and write expectations

Preview must require explicit verification_preview mode, its flag, current canonical actor/project authority, current eligible exact source and full existing byte-bound read coverage. Unknown/mixed branch properties, facts in description mode and client-supplied authority refuse. Actual registered handler output remains persisted:false, reviewState:not_recorded and scientificQualification:unassessed. Preview must cause no description write, embedding or audit call. No aggregate receipt may be described as extraction-specific or current-actor/current-turn proof.

Description snapshots precede the embedding await. Mutating a caller-owned key_data/proposer object during that await cannot alter the saved/check-audited object; changing extraction, bytes, organization, program, version currentness, disposition, active membership, persisted role or private-project access cannot yield a successful write. Exactly one conditional RETURNING receipt is required. Zero-row updates, persistence/admission/audit errors and ordinary vector errors cannot be laundered by vector fallback. Only specifically unavailable vector operations may fall back. A supplied review extraction digest must match; old revision-only reviews remain whole-header decisions with context not recorded. Existing confirmed/corrected history remains visible, with an explicit current-use caveat when needed.
