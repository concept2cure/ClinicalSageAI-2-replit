  ✓ refuses a new screen the plan does not approve

  ✓ refuses a Completes trailer naming nothing that existed
  ✓ accepts a commit that names what it completes

  ✓ a commit before RULE 6 is not asked for one
  ✓ refuses a new route file
  ✓ refuses a new service
  ✓ refuses a new AnA tool
