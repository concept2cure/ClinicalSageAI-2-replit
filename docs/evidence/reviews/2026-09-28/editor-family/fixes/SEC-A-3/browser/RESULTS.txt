# Conclusions
1. No sandbox value lets Chromium show a PDF: '', allow-same-origin, allow-scripts allow-same-origin, and every allow-* token together all give chrome-error://chromewebdata.
2. The csp attribute (CSP Embedded Enforcement) keeps the extension frame but stops the viewer's own script: no <pdf-viewer> element, nothing rendered.
3. Unsandboxed + application/pdf: the viewer loads the PDF (pageCount 1). HTML bytes typed application/pdf go to the viewer too (pageCount 0) — never to the HTML parser.
=> The strictest configuration that still shows a PDF in Chromium is an unsandboxed frame; the control is the input: %PDF bytes, typed application/pdf.
