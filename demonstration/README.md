# ICH Validation Demonstration Packages

This directory contains sample eCTD packages for demonstrating ICH structure validation:

## Valid Package

- Complete package with all required modules (m1-m5)
- Properly structured with correct folder hierarchy
- Should pass validation successfully

## Missing M1 Package

- Missing required administrative content in m1 module
- Should fail validation with specific error about missing m1 content

## Incorrect Structure Package

- Files placed in incorrect locations
- Violates ICH structural requirements
- Should fail validation with structural errors

## Completed Package

- Comprehensive example with multiple files in each module
- Complete folder structure following ICH guidelines
- Demonstrates a real-world compliant submission

## How to Use

1. Navigate to the CoAuthor page
2. Select files from one of these demonstration packages
3. Click "Compile Submission" to see validation results
4. Try different packages to see different validation outcomes
