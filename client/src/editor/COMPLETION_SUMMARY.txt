🎯 KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔒 ATOM PROTECTION
   User cannot manually edit numbers → Prevents data integrity violations

📊 CHAIN OF CUSTODY
   Every value tracks: Dataset | Variable | Version | Source | Timestamps

✅ STATUS SYSTEM
   🟡 Draft (amber) → Not yet QC'd
   🟢 Verified (green) → Passed validation
   🔴 Stale (red, pulsing) → Source data changed
   🔵 Frozen (blue, 🔒) → Locked for submission

📈 VERSION CONTROL
   Detects when SAS datasets update → Flags stale tags → Prevents FDA RTF

💻 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Import Extension
   ┌──────────────────────────────────────────────────────────────┐
   │ import { SmartTag } from '@/editor/extensions/SmartTag';     │
   │                                                              │
   │ const editor = useEditor({                                   │
   │   extensions: [StarterKit, SmartTag],                        │
   │ });                                                          │
   └──────────────────────────────────────────────────────────────┘

2. Insert Tag
   ┌──────────────────────────────────────────────────────────────┐
   │ editor.commands.insertSmartTag({                             │
   │   value: '45.3',       // Display value                      │
   │   rawValue: '45.2876', // Exact SAS output                   │
   │   dataset: 'ADSL',     // CDISC domain                       │
   │   variable: 'AGE',     // Statistical variable               │
   │   status: 'verified',  // QC status                          │
   │ });                                                          │
   └──────────────────────────────────────────────────────────────┘

3. Visual Result
   ┌──────────────────────────────────────────────────────────────┐
   │ Mean age was [45.3] years (verified, green chip)             │
   │              ^^^^^^                                          │
   │         SmartTag with full traceability                      │
   └──────────────────────────────────────────────────────────────┘

📋 USE CASE EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before (Plain Text - Risky):
┌─────────────────────────────────────────────────────────────────────┐
│ The median overall survival was 24.5 months (p = 0.0342).           │
│                                                                      │
│ ❌ No traceability                                                   │
│ ❌ User can accidentally change "24.5" → "24.4"                      │
│ ❌ If source data updates, no way to detect stale values            │
│ ❌ FDA asks "Where did 0.0342 come from?" → Cannot answer           │
└─────────────────────────────────────────────────────────────────────┘

After (SmartTag - Compliant):
┌─────────────────────────────────────────────────────────────────────┐
│ The median overall survival was [24.5] months (p = [0.0342]).       │
│                                  ^^^^^^            ^^^^^^^^          │
│                          ADTTE/MEDOS_OS      ADTTE/PVAL_OS          │
│                            v1.0 verified      v1.0 verified         │
│                                                                      │
│ ✅ Complete Chain of Custody                                         │
│ ✅ User CANNOT edit values manually (atom protection)                │
│ ✅ If ADTTE v2.0 released → Tags turn red (stale)                    │
│ ✅ FDA asks source → Hover shows: ADTTE/PVAL_OS v1.0 verified       │
└─────────────────────────────────────────────────────────────────────┘

📊 TECHNICAL ARCHITECTURE

TipTap Extension (SmartTag.js)
   ↓
   ├─ addAttributes() → 10 regulatory attributes
   ├─ parseHTML() → Extract from <smart-tag> elements
   ├─ renderHTML() → Serialize with all metadata
   ├─ renderText() → Plain text export (value only)
   ├─ addCommands() → editor.commands.insertSmartTag()
   └─ addNodeView() → ReactNodeViewRenderer(SmartTagChip)
      ↓
      React Component (SmartTagChip.tsx)
         ├─ Status-based color coding
         ├─ Hover tooltips with metadata
         ├─ Lock icon for frozen tags
         └─ Pulse animation for stale tags
            ↓
            CSS Styling (smarttag.css)
               ├─ .status-draft (amber)
               ├─ .status-verified (green)
               ├─ .status-stale (red, pulsing)
               └─ .status-frozen (blue, locked)
