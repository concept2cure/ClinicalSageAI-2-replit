# AI Agent Instructions (ClinicalSageAI)

These instructions apply to all AI-assisted changes in this repository.

## Project Overview

- Stack: TypeScript, Node.js, React (Vite), PostgreSQL (Drizzle ORM)
- Key directories:
  - server/: backend APIs, services, middleware
  - client/src/: UI components and pages
  - shared/: shared types, utilities, and schemas
  - docs/: architecture, compliance, and operations guidance

## Architecture & Conventions

- Read architecture docs before major changes:
  - docs/ARCHITECTURE.md
  - docs/adr/ (Architecture Decision Records)
- Follow existing patterns; do not introduce new frameworks without an ADR.
- Avoid changes in \_deprecated/ paths.
- Keep files under 500 lines where possible.

## Testing Expectations

- Update or add tests for behavior changes.
- Prefer targeted unit tests and API/integration tests.
- Ensure coverage is meaningful (edge cases, failure paths, permission checks).
- Run scripts/ai/verify-tests.sh before submitting changes.

## Security & Compliance

- Treat any auth, audit, and compliance code as critical paths.
- Avoid logging PHI/PII.
- Prefer parameterized queries and validated input schemas.

## Documentation

- Update relevant docs when behavior or architecture changes.
- If a decision is architectural, add or update an ADR.
- Use scripts/ai/context-pack.sh for AI sessions to minimize context drift.

## PR Hygiene

- Keep PRs small and focused.
- Provide a clear summary and testing notes.
- If AI was used, confirm edge-case test coverage in the PR checklist.
