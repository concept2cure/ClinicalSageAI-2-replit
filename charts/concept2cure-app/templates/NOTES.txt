{{ include "concept2cure-app.fullname" . }} deployed.

1. Wait for the pod to become ready:
   kubectl -n {{ .Values.namespaceOverride | default .Release.Namespace }} rollout status deploy/{{ include "concept2cure-app.fullname" . }}

2. Reach the app:
{{- if .Values.ingress.enabled }}
   via your Ingress host(s): {{ range .Values.ingress.hosts }}{{ .host }} {{ end }}
{{- else }}
   kubectl -n {{ .Values.namespaceOverride | default .Release.Namespace }} port-forward svc/{{ include "concept2cure-app.fullname" . }} 8080:{{ .Values.service.port }}
   # then open http://localhost:8080/api/health
{{- end }}

3. First-run admin (private install, no demo user). Needs the SETUP_TOKEN you
   set in the Secret (production closes setup without one):
   curl -X POST http://<host>/api/setup/initialize \
     -H 'content-type: application/json' \
     -H 'X-Setup-Token: <your SETUP_TOKEN>' \
     -d '{"email":"admin@your-org.com","password":"<strong-password>","organizationName":"Your Org"}'
   # This endpoint self-closes once the first user exists.

NOTE: DATABASE_URL must point at a pgvector-capable PostgreSQL (RDS 15.2+,
Cloud SQL, or a pgvector image). The bundled postgresql dependency is disabled
by default — see values.yaml.
